# Workflows

Đọc [`DEVELOPMENT_WORKFLOW.md`](DEVELOPMENT_WORKFLOW.md) để áp dụng Lean Development Workflow; dùng lại nội dung đã biết nếu chưa thay đổi. Chỉ mở hướng dẫn chi tiết cần dùng, không bắt buộc đọc tất cả tài liệu sau cho mỗi nhiệm vụ:

1. [`ANALYSIS.md`](ANALYSIS.md) — xác định yêu cầu.
2. [`DESIGN.md`](DESIGN.md) — thiết kế giải pháp.
3. [`IMPLEMENTATION.md`](IMPLEMENTATION.md) — triển khai.
4. [`TESTING.md`](TESTING.md) — kiểm thử.
5. [`REVIEW.md`](REVIEW.md) — rà soát.
6. [`COMPLETION.md`](COMPLETION.md) — xác nhận và bàn giao ngắn.

Nếu không đạt điều kiện chuyển bước, quay lại giai đoạn phù hợp; không đánh dấu chức năng hoàn thành khi chưa có bằng chứng.

[`CI.md`](CI.md) mô tả Backend CI trên GitHub Actions, database test riêng, thứ tự kiểm tra và giới hạn kiểm chứng local.
