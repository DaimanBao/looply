# Tài liệu Looply — Đồ án 1

Đây là **bản đồ đọc tài liệu**, không thay thế quy tắc trong `AGENTS.md` (đặt tại root repository).

## Thứ tự đọc khi bắt đầu
1. [`PROJECT_OVERVIEW.md`](PROJECT_OVERVIEW.md) — mục tiêu, phạm vi sản phẩm.
2. [`TECH_STACK.md`](TECH_STACK.md) — công nghệ và phiên bản.
3. [`requirements/FUNCTIONAL_REQUIREMENTS.md`](requirements/FUNCTIONAL_REQUIREMENTS.md) — **checklist tiến độ duy nhất** của 88 chức năng.
4. [`requirements/README.md`](requirements/README.md) — chọn module cần làm; chỉ đọc đặc tả module liên quan.
5. [`database/README.md`](database/README.md) — bản thiết kế dữ liệu và những điểm cần xác minh trước migration.
6. [`structures/README.md`](structures/README.md) — vị trí code và trách nhiệm các tầng.
7. [`workflows/DEVELOPMENT_WORKFLOW.md`](workflows/DEVELOPMENT_WORKFLOW.md) — quy trình thực hiện; mở file giai đoạn cần dùng.

[`DOCUMENTATION_GUIDE.md`](DOCUMENTATION_GUIDE.md) quy định cách cập nhật và giải quyết mâu thuẫn tài liệu. Không cần đọc tất cả module hay workflow cho mọi nhiệm vụ.
